## Evidence of Work


### RAG Projects Collection


A local-first retrieval-augmented generation service that:


- Ingests and extracts text from PDF documents.
- Splits content into retrieval-ready chunks.
- Generates local embeddings with Ollama and mxbai-embed-large.
- Searches context with FAISS semantic retrieval.
- Answers with Groq or a local llama3.2:3b fallback.
- Runs behind FastAPI and ships as a Docker image.


[Read the implementation and setup guide](https://github.com/mahmoudelhamshryy/rag-projects)
